# Security Policy

## Reporting a Vulnerability

To report a security vulnerability, please email the maintainers at [hammrouni.khaled@gmail.com](mailto:hammrouni.khaled@gmail.com).

## Key Material and Prompts Handling

Key material and prompts are handled per the security notes in the [README](../README.md). Please refer to that document for details on how sensitive data is managed within the system.

## Supported Versions

Please report vulnerabilities in the latest released version of Palimpsest Gateway.
