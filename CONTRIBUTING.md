# Contributing to Palimpsest Gateway

Thank you for considering contributing to Palimpsest Gateway! Please read this document to understand how to contribute effectively.

## Development Process

For the complete development loop, including setting up the environment, running tests, and submitting pull requests, please refer to the [Development Guide](docs/DEVELOPMENT.md).

## CI Requirements

Before submitting a pull request, ensure the following checks pass:

- Run the test suite: `pytest`
- Run the linter: `ruff check app/ tests/`

These checks are also run automatically by continuous integration.

## Reporting Issues

Please use the [issue tracker](https://github.com/hammrouni/palimpsest-gateway/issues) to report bugs or request features.

## Pull Requests

1. Fork the repository and create a new branch from `main`.
2. Make your changes, ensuring you follow the coding standards and include tests where appropriate.
3. Run the test suite and linter as described above.
4. Submit a pull request with a clear description of your changes.

Thank you for your contribution!
